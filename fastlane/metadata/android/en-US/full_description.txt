QRServ takes any selected files on your device and makes them available through its own HTTP server at an unused port number. The selected files can then be downloaded via web browser on another device and/or software that allows file downloads over HTTP from QR codes.
Devices involved would need to be on the same network (i.e. access point, tethering [no mobile data required], VPN [with a supported configuration]).

Features:

- QR Code
-- Tap to show the URL in a tooltip
-- Press and hold to copy the URL to the clipboard
- Share sheet
-- Share the download URL via the system share sheet
-- Import files via the system share sheet from other apps
-- Sharing text with the app creates a text file to share
- Shows live import progress, whether for a single file or multiple
- Multi-file selection
-- Bundled into a ZIP archive
-- Press and hold the archive's filename to see the originally selected files in a tooltip
- Direct Access Mode -- serves the file directly from storage instead of copying it into app cache first, ideal for large files
-- Single file selection only
-- Always available on the GitHub release; Play Store builds only support it on Android 10 or earlier (due to Manage External Storage restrictions)
-- Toggle-able in settings
- Detects if the selected file is removed while being served, or modified (Direct Access Mode only)
- Show or hide the filename in the download URL
- Notifies when a client requests or finishes downloading the file, including their IP address
- Resumes interrupted downloads in supported software
- Choose which network interface's IP address to serve from -- the server only listens there unless set to listen on all interfaces
- Switches to another IP address if the selected one disappears, and suggests better ones as they appear
- Private hotspot (Android 13 or later) -- shares over a Wi-Fi network the app creates, reachable only by devices you let join
-- Scan a Wi-Fi QR code to join, or enter the network name and password by hand
-- Switch an ongoing share to or from the private hotspot without selecting the file again
-- Chooses 5 GHz for faster transfers on Android 16 or later (not all devices support 5 GHz or choosing the band)
- Keeps sharing while the app is in the background, with a notification to stop sharing
- Stops sharing when idle (10 minutes by default, adjustable)
- HTTP server binds to a random free port by default, or a user-configured one
- In-app theme selection
- Supports various languages: English, French, German, Hungarian, Italian, Polish, Portuguese, Spanish, Russian, Turkish, Persian, Hebrew

Permission usage:

- INTERNET -- Listing network interfaces and binding the HTTP server's port
- READ_EXTERNAL_STORAGE -- Read-only access to internal storage, SD cards and USB drives
- FOREGROUND_SERVICE and FOREGROUND_SERVICE_CONNECTED_DEVICE -- Keeping the server (and private hotspot) running in the background
- POST_NOTIFICATIONS -- The ongoing sharing notification, with the option to stop sharing
- WAKE_LOCK -- Keeping the device awake while on the file sharing screen
- CHANGE_WIFI_STATE -- Starting and stopping the private hotspot
- NEARBY_WIFI_DEVICES -- Creating the private hotspot (Android 13 or later). Not used to locate devices
- ACCESS_WIFI_STATE -- Checking if the device can host a hotspot while staying on Wi-Fi
- ACCESS_NETWORK_STATE -- Noticing IP address changes while sharing, so the QR code can follow
- MANAGE_EXTERNAL_STORAGE -- Direct access to selected files on internal storage instead of caching them first (only outside Google Play)

QRServ is open source.
https://github.com/uintdev/qrserv
